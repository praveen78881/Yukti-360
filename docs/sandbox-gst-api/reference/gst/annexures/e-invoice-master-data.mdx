This page lists the official NIC master values used in Sandbox [Generate e-Invoice](/api-reference/gst/compliance/endpoints/e-invoice/generate_e_invoice) requests. Use each code only with its named field; a code from one list is not valid for another field. For the separate E-Way Bill values, see [E-Way Bill master data](/api-reference/gst/annexures/e-way-bill-master-data).

<Note>
  Source: [NIC E-Invoice master codes](https://einvoice1.gst.gov.in/Others/MasterCodes). Reviewed 20 July 2026. NIC can amend these values, so check the official list before changing an integration.
</Note>

## Request field index

| Master data | Request field | Use |
| --- | --- | --- |
| State | `SellerDtls.Stcd`, `BuyerDtls.Stcd`, `BuyerDtls.Pos`, `DispDtls.Stcd`, `ShipDtls.Stcd` | State and place-of-supply codes. |
| Country | `ExpDtls.CntCode`, `ItemList[].OrgCntry` | Export and item-origin country codes. |
| Port | `ExpDtls.Port` | Export port code. |
| Currency | `ExpDtls.ForCur` | Foreign currency code. |
| UQC | `ItemList[].Unit` | Item unit quantity code. |
| Pincode mapping | `SellerDtls.Pin`, `BuyerDtls.Pin`, `DispDtls.Pin`, `ShipDtls.Pin` | Pair each pincode with the corresponding `Stcd`. `BuyerDtls.Pos` is a place-of-supply state code, not a pincode mapping. |
